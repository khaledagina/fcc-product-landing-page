# Focusly Landing Page

Landing page for Focusly, a fictional focus-timer app for students. The video is the Pomodoro Technique explainer by Francesco Cirillo on YouTube. Prices and the signup form are demo only.

This is a **freeCodeCamp Responsive Web Design certification project**, redesigned. The original submission followed freeCodeCamp's required user stories. This version keeps those requirements (ids, structure, semantics) and rebuilds the visual design, content and interactions.

**Live demo:** https://khaledagina.github.io/fcc-product-landing-page/

![Focusly landing page, desktop view](https://github.com/user-attachments/assets/2506bda0-ecd5-4840-b0dd-2f0a8fa84f91)

## What changed in the redesign
- New fictional product, copy, logo and pricing (the original used the sample product)
- Animated timer hero, feature cards, steps, pricing and signup form
- Fixed navigation bar and scroll reveal animations

## Built with
- HTML5 and semantic elements
- CSS3 (custom properties, Flexbox, Grid, media queries)
- A small amount of vanilla JavaScript
- Responsive from 320px up, keyboard focus styles, `prefers-reduced-motion` support

## Run locally
Open `index.html` in a browser. No build step.
